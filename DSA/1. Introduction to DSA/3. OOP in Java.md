# PART 3: Object-Oriented Programming in Java

## 3.1 Class and Object

A class is a blueprint used to create objects.

An object is an instance of a class.

## 3.2 Constructors

A constructor initializes an object.

**Types:**

- No-argument constructor
- Parameterized constructor

## 3.3 Four Pillars of OOP

1. Encapsulation
   Combining data and methods in a class and controlling access to data.

2. Inheritance
   One class acquiring properties and methods of another class.

3. Polymorphism
   One interface or method name representing different behaviors.

**Types:**

- Compile-time polymorphism
- Runtime polymorphism

4. Abstraction
   Hiding implementation details and showing essential functionality.

Achieved through:

- Abstract classes
- Interfaces

## 3.4 Overloading vs Overriding

| **Overloading**                 | **Overriding**                    |
| ------------------------------- | --------------------------------- |
| Same name, different parameters | Same method signature in subclass |
| Compile-time polymorphism       | Runtime polymorphism              |

## 3.5 Access Modifiers

- private
- default
- protected
- public

## 3.6 static and final Keywords

- static: Belongs to the class.
- final variable: Cannot be reassigned.
- final method: Cannot be overridden.
- final class: Cannot be extended.

## 3.7 String in Java

String is immutable

```java
String s = "Hello";
s = s.concat(" World");
System.out.println(s);
```

```text
Hello World
```
