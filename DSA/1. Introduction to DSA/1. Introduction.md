# PART 1: Introduction to DSA

## 1.1 What is Data?

Data refers to raw facts and figures that can be processed by a computer.

Examples:

- Student name
- Student roll number
- Employee salary
- Product price

## 1.2 What is a Data Structure?

A data structure is a way of organizing, storing and managing data so that it can be accessed and modified efficiently.

Examples:

- Array
- Linked List
- Stack
- Queue
- Tree
- Graph
- Hash Table

** Why Do We Need Data Structures?**

1. Efficient data storage.
2. Faster searching.
3. Faster insertion and deletion.
4. Better memory utilization.
5. Efficient data processing.
6. Handling large amounts of information.

## 1.3 What is an Algorithm?

An algorithm is a finite sequence of well-defined steps used to solve a particular problem.

Example: Adding two numbers.

1. Start.
2. Read A and B.
3. Calculate SUM = A + B.
4. Display SUM.
5. Stop.

## 1.4 What is DSA?

DSA stands for:

- Data Structures
- Algorithms
  Data structures organize data, while algorithms process that data to solve problems.

Example:

Suppose we want to search for a student in a database.

- Data Structure: Array or HashMap.
- Algorithm: Linear Search or Hash-based lookup.

## 1.5 Types of Data Structures

Data structures can be classified into two major categories.

### 1. Primitive Data Structures

These are fundamentals data types provided by a programming language.

Examples in Java:

| Data Type | Example |
| --------- | ------- |
| int       | 100     |
| float     | 10.5f   |
| double    | 25.75   |
| char      | 'A'     |
| boolean   | true    |
| byte      | 10      |
| short     | 100     |
| long      | 100000L |

### 2. Non-Primitive Data Structures

These are more complex structures used to organize collections of data.

They are commonly classified into:

1. **Linear Data Structures**

Elements are arranged sequentially.

Examples:

- Array
- Linked List
- Stack
- Queue

2. **Non-Linear Data Structures**

Elements are organized hierarchically or through interconnected relationships.

Examples:

- Tree
- Graph

## 1.7 Linear vs Non-Linear Data Structures

| Feature     | Linear              | Non-Linear                    |
| ----------- | ------------------- | ----------------------------- |
| Arrangement | Sequential          | Hierarchical & interconnected |
| Traversal   | Usally sequential   | Multiple possible paths       |
| Complexity  | Generally simpler   | Generally more complex        |
| Examplex    | Array, Stack, Queue | Tree, Graph                   |

## 1.8 Static vs Dynamic Data Structures

Size is fixed or determined when the structure is created.

Example:

```java
int[] arr = new int[5];
```

The array length cannot be changed after creation.

### Dynamic Data Structure

Can grow or shrink during program execution.

Examples:

- ArrayList
- LinkedList
- Stack implemented using linked nodes

Java example:

```java

import java.util.ArrayList;

class Main {
    public static void main(String[] args) {

        ArrayList<Integer> list = new ArrayList<>();

        list.add(10);
        list.add(20);
        list.add(30);

        System.out.println(list);
    }
}

```

| Static         | Dynamic                        |
| -------------- | ------------------------------ |
| Fixed size     | Can grow or shrink             |
| Example: Array | Example: ArrayList, LinkedList |

## 1.9 Abstract Data Type (ADT)

An Abstract Data Type defines what operations can be performed on data without specifying exactly how those operations are implemented.

Examples:

**Stack ADT**
Operations:

- push()
- pop()
- peek()
- isEmpty()

**Queue ADT**

Operations:

- enqueue()
- dequeue()
- front()
- isEmpty()

Important distinction:

- ADT describes behavior.
- Data structure describes implementation.
