# PART 2: Java Fundamentals

## 2.1 What is Java?

Java is a high-level, object-oriented, class-based programming language.

Features:

- Platform independent
- Object-oriented
- Secure
- Robust
- Multithreaded
- Automatic memory management

## 2.2 JDK, JRE and JVM

| JDK                      | JRE                  | JVM                    |
| ------------------------ | -------------------- | ---------------------- |
| Development kit          | Runtime environment  | Executes bytecode      |
| Used to develop programs | Used to run programs | Executes Java bytecode |

```text

Java Source Code
       |
       v
   Compiler (javac)
       |
       v
  Bytecode (.class)
       |
       v
       JVM
       |
       v
 Machine Execution

```

Java source code is compiled into platform-independent bytecode, which is executed by a platform-specific JVM.

## 2.5 Type Casting

Type casting converts one data type into another.

**Widening Casting**
Smaller type to larger compatible type.

```java
int a = 10;

double b = a;

System.out.println(b);

```

```text
10.0

```

**Narrowing Casting**
Larger type to smaller type.

```java
double a = 10.75;

int b = (int) a;

System.out.println(b);

```

```text
10

```

Note: Narrowing can result in loss of information.

## 2.7 Methods

A method is a block of code that performs a particular task.

```java
class Main {
    static int add(int a, int b) {
        return a + b;
    }

    public static void main(String[] args) {
        System.out.println(add(10, 20));
    }
}
```

Output:

```text
30
```
