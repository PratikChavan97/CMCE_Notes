# Part 4: Java Arrays, Strings and Collections

## 4.1 What is an Array?

An array is a fixed-size data structure that stores elements of the same type

```java
int[] arr = {10, 20, 30, 40, 50};
```

## 4.2 Array Traversal

```java
int[] arr = {10, 20, 30};

for (int i = 0; i < arr.length; i++) {
    System.out.println(arr[i]);
}
```

## 4.3 Two-Dimensional Array

```java
int[][] matrix = {
    {1, 2, 3},
    {4, 5, 6},
    {7, 8, 9}
};
```

## 4.6 ArrayList

Resizable array implementation of List.

```Java
import java.util.ArrayList;

class Main {
    public static void main(String[] args) {
        ArrayList<Integer> list = new ArrayList<>();

        list.add(10);
        list.add(20);
        list.add(30);

        System.out.println(list);
    }
}
```

## 4.10 Array vs ArrayList vs LinkedList

| Feature         | Array | ArrayList | LinkedList |
| --------------- | ----- | --------- | ---------- |
| Size            | Fixed | Dynamic   | Dynamic    |
| Index Access    | O(1)  | O(1)      | O(n)       |
| Memory overhead | Low   | Moderate  | Higher     |
