## PART 3: Mathematics and Number Theory for DSA

Mathematics forms the foundation for designing optimized algorithms, eliminating unnecessary iterations, and preventing runtime integer overflows.

### 3.1 Arithmetic Operations and Modulo Arithmetic

| Operation          | Operator | Formula / Identity      | Properties                                                      |
| :----------------- | :------: | :---------------------- | :-------------------------------------------------------------- |
| **Addition**       |   `+`    | $(a + b)$               | $(a + b) \pmod m = ((a \pmod m) + (b \pmod m)) \pmod m$         |
| **Subtraction**    |   `-`    | $(a - b)$               | $(a - b) \pmod m = ((a \pmod m) - (b \pmod m) + m) \pmod m$     |
| **Multiplication** |   `*`    | $(a \cdot b)$           | $(a \cdot b) \pmod m = ((a \pmod m) \cdot (b \pmod m)) \pmod m$ |
| **Division**       |   `/`    | $\lfloor a / b \rfloor$ | Requires Modular Multiplicative Inverse under modulo            |
| **Remainder**      |   `%`    | $a \pmod b$             | $a = b \cdot q + r$, where $0 \le r < b$                        |

> **Preventing Negative Modulo in Java:**
> In Java, `-7 % 3` yields `-1`. To obtain a true positive residue in competitive programming:
>
> ```java
> int mod = ((val % m) + m) % m;
> ```

### 3.2 Finding the Number of Digits in $N$

To determine the number of digits $D$ in a positive integer $N$:

#### Iterative Approach: $\mathcal{O}(\log_{10} N)$

```java
int countDigits(int n) {
    int count = 0;
    while (n > 0) {
        n /= 10;
        count++;
    }
    return count;
}
```

#### Mathematical Approach: $\mathcal{O}(1)$

$$D = \lfloor \log_{10} N \rfloor + 1$$

```java
int countDigitsFast(int n) {
    if (n == 0) return 1;
    return (int) Math.floor(Math.log10(Math.abs(n))) + 1;
}
```

### 3.3 Greatest Common Divisor (GCD) / HCF

The greatest common divisor of two integers $a$ and $b$ is the largest integer dividing both without remainder.

#### Euclidean Algorithm

Based on the identity: $\gcd(a, b) = \gcd(b, a \pmod b)$ where $\gcd(a, 0) = a$.

```java
// Time Complexity: O(log(min(a, b)))
// Space Complexity: O(log(min(a, b))) auxiliary stack
int gcd(int a, int b) {
    return (b == 0) ? a : gcd(b, a % b);
}

// Iterative Form: O(1) Auxiliary Space
int gcdIterative(int a, int b) {
    while (b != 0) {
        int temp = b;
        b = a % b;
        a = temp;
    }
    return a;
}
```

#### Least Common Multiple (LCM)

$$\text{LCM}(a, b) = \frac{a \times b}{\gcd(a, b)}$$

_To prevent intermediate integer overflow:_

```java
long lcm(long a, long b) {
    return (a / gcd((int)a, (int)b)) * b;
}
```

### 3.4 Primality Testing

A prime number is an integer $n > 1$ with exactly two distinct positive divisors: $1$ and $n$.

#### Optimal Trial Division: $\mathcal{O}(\sqrt{n})$

Divisors always occur in complementary pairs $(d, \frac{n}{d})$. If $n$ has a factor, at least one must satisfy $d \le \sqrt{n}$.

```java
boolean isPrime(int n) {
    if (n <= 1) return false;
    if (n <= 3) return true; // 2 and 3
    if (n % 2 == 0 || n % 3 == 0) return false;

    // Check factors of form 6k +/- 1
    for (int i = 5; i * i <= n; i += 6) {
        if (n % i == 0 || n % (i + 2) == 0) {
            return false;
        }
    }
    return true;
}
```

### 3.5 Sieve of Eratosthenes

Generates all primes up to $N$ with efficiency:

$$\mathcal{O}(N \log(\log N))$$

```java
boolean[] sieveOfEratosthenes(int n) {
    boolean[] isPrime = new boolean[n + 1];
    Arrays.fill(isPrime, true);
    isPrime[0] = false;
    isPrime[1] = false;

    for (int p = 2; p * p <= n; p++) {
        if (isPrime[p]) {
            for (int i = p * p; i <= n; i += p) {
                isPrime[i] = false;
            }
        }
    }
    return isPrime;
}
```

### 3.6 Fast Modular Exponentiation

Calculates $(x^y) \pmod m$ in $\mathcal{O}(\log y)$ time using binary exponentiation instead of naive $\mathcal{O}(y)$.

$$
x^y =
\begin{cases}
1 & \text{if } y = 0 \\
(x^{y/2})^2 & \text{if } y \text{ is even} \\
x \cdot (x^{(y-1)/2})^2 & \text{if } y \text{ is odd}
\end{cases}
$$

```java
long powerMod(long base, long exp, long mod) {
    long result = 1;
    base = base % mod;

    while (exp > 0) {
        if ((exp & 1) == 1) { // If exp is odd
            result = (result * base) % mod;
        }
        base = (base * base) % mod;
        exp >>= 1; // exp = exp / 2
    }
    return result;
}
```

### 3.7 Even and Odd Numbers

A number is even if it is divisible by 2.

A number is odd if it is not divisible by 2.

Java program:

```java
class Main {

    public static void main(String[] args) {

        int n = 15;

        if (n % 2 == 0) {
            System.out.println("Even");
        } else {
            System.out.println("Odd");
        }
    }
}
```

Time Complexity: O(1)

Auxiliary Space: O(1)

### 3.8 Prime Numbers

A prime number is a natural number greater than 1 that has exactly two positive divisors: 1 and itself.

```java
class Main {

    public static void main(String[] args) {

        int n = 29;
        boolean isPrime = true;

        if (n <= 1) {
            isPrime = false;
        } else {

            for (int i = 2; i <= n / i; i++) {

                if (n % i == 0) {
                    isPrime = false;
                    break;
                }
            }
        }

        if (isPrime) {
            System.out.println("Prime");
        } else {
            System.out.println("Not Prime");
        }
    }
}
```

Time Complexity: O(√n)

Auxiliary Space: O(1)

Why check only up to √n?

If n = a × b, at least one factor must be less than or equal to √n.

Therefore, checking beyond √n is unnecessary.

Examples: 2, 3, 5, 7, 11, 13.
