## PART 1: Introduction to Algorithms

### 1.1 What is an Algorithm?

An **algorithm** is a finite sequence of unambiguous, well-defined instructions designed to solve a computational problem. It accepts valid inputs, processes them methodically, and produces an expected output.

```
+------------+       +-------------------+       +-------------+
|   Input    |  -->  | Algorithm (Logic) |  -->  |   Output    |
+------------+       +-------------------+       +-------------+
```

#### Example: Algorithm to Add Two Numbers

1. **Start**
2. **Read** two numbers $A$ and $B$.
3. **Calculate** $\text{SUM} = A + B$.
4. **Display** $\text{SUM}$.
5. **Stop**

#### Java Implementation

```java
public class Main {
    public static void main(String[] args) {
        int a = 10;
        int b = 20;

        int sum = a + b;

        System.out.println("Sum = " + sum);
    }
}
```

**Output:**

```text
Sum = 30
```

### 1.2 Characteristics of an Algorithm

Every standard algorithm must satisfy the following core criteria:

1. **Input:** Accepts zero or more externally supplied values.
2. **Output:** Produces at least one quantifiable result.
3. **Definiteness:** Every operation is clear, unambiguous, and mathematically precise.
4. **Finiteness:** Terminates after a finite number of steps for all valid input configurations.
5. **Effectiveness:** Every instruction is feasible and can be carried out within finite time using finite resources.
6. **Generality:** Solves all valid instances of the target problem class rather than a single specific case.

### 1.3 Algorithm vs Program

| Feature         | Algorithm                     | Program                                              |
| :-------------- | :---------------------------- | :--------------------------------------------------- |
| **Definition**  | Step-by-step logical design   | Concrete implementation of logic                     |
| **Portability** | Language-independent          | Dependent on a specific language (Java, C++, Python) |
| **Focus**       | Mathematical & logical design | Syntax, compilation, and execution                   |
| **Execution**   | Cannot be executed directly   | Compiles and executes on physical hardware           |

### 1.4 What is Pseudocode?

**Pseudocode** is an informal, language-agnostic representation of an algorithm using structured, programming-like phrasing.

#### Example: Find the Largest of Two Numbers

```text
START

INPUT A, B

IF A > B THEN
    PRINT A
ELSE
    PRINT B
END IF

STOP
```

#### Core Advantages:

- Simple to read and write without strict syntax overhead.
- Bridges abstract algorithmic thinking and source code implementation.
- Enables rapid design verification and modular refinement.

### 1.5 Flowcharts

A **flowchart** is a standardized graphical model illustrating control flow and operations within an algorithm.

#### Common Flowchart Symbols

| Symbol             | Shape              | Meaning                                 |
| :----------------- | :----------------- | :-------------------------------------- |
| **Terminator**     | Oval / Rounded Box | Start / Stop                            |
| **Process**        | Rectangle          | Computational operations or assignments |
| **Input / Output** | Parallelogram      | Reading input or printing output        |
| **Decision**       | Diamond            | Conditional checks with branching paths |
| **Flowline**       | Arrow              | Direction of execution                  |
| **Connector**      | Small Circle       | Merges separate execution paths         |

#### Flowchart Example: Even or Odd

### 1.6 Types of Algorithm Design Paradigms

```
                      ALGORITHM PARADIGMS
                               |
     +------------+------------+------------+---------------+
     |            |            |            |               |
     v            v            v            v               v
Brute Force  Divide & Conquer Greedy   Dynamic Prog.   Backtracking
```

1. **Brute Force:** Evaluates candidate solutions directly and exhaustively.
   - _Examples:_ Linear Search, simple string matching.
2. **Divide and Conquer:** Recursively breaks a problem into smaller disjoint subproblems, solves them independently, and combines their solutions.
   - _Examples:_ Merge Sort, Quick Sort, Binary Search.
3. **Greedy Method:** Builds a solution piece-by-piece, always choosing the locally optimal candidate at each step.
   - _Examples:_ Fractional Knapsack, Prim's and Kruskal's MST, Activity Selection.
4. **Dynamic Programming (DP):** Solves problems with overlapping subproblems and optimal substructure by caching results (memoization / tabulation).
   - _Examples:_ 0/1 Knapsack, Longest Common Subsequence (LCS), Fibonacci series.
5. **Backtracking:** Incrementally builds solution vectors, abandoning ("pruning") paths as soon as they violate problem constraints.
   - _Examples:_ $N$-Queens puzzle, Sudoku solver, Graph Coloring, Hamiltonian Cycle.
